1. Introduction

1.1 Background of the Project

Music genre classification is a multiclass machine learning problem that aims to predict the genre of a song based on its measurable audio characteristics. In this project, the Spotify Tracks Dataset is used to classify songs according to the target variable track_genre. The predictor variables include audio and track-level features such as popularity, duration, danceability, energy, loudness, speechiness, acousticness, instrumentalness, liveness, valence, and tempo.

This task is challenging because many genres may share similar musical characteristics. For example, songs from different genres may have similar tempo, energy, or danceability values, making it difficult for a model to distinguish between them. Therefore, both overall performance and class-level errors need to be examined carefully.

1.2 Phase 2 Objective

The objective of Phase 2 is to implement the initial Random Forest classification model proposed in Phase 1. The model is trained using selected Spotify audio features and evaluated on a separate test set. The main evaluation metrics include accuracy and F1-score.

In addition to measuring overall performance, this phase also focuses on analysing the model’s prediction errors. A confusion matrix is used to identify which genres are correctly classified and which genres are frequently confused. This provides useful evidence for understanding the strengths and limitations of the initial model.

1.3 Link to Phase 1 Plan

Phase 2 directly follows the project plan developed in Phase 1. In Phase 1, Random Forest was selected as the main modelling approach, and evaluation metrics such as accuracy, F1-score, and confusion matrix analysis were planned. Phase 2 implements these planned tasks by training the initial model, evaluating its performance, and interpreting the classification results.

Overall, this phase provides the first experimental results of the project and forms the foundation for future model improvement and refinement.

3. Methodology

3.1 Model Choice - Random Forest

Random Forest was selected as the main classification for Phase 2. It is an ensemble learning method that builds multiple decision trees and combines their prediction to produce a final classification result.

Compare with single decision tree, Random Forest can reduce overfitting and improve model stability.

This model is suitable for the Spotify genre classification task because the target variable track_genre contains multiple genre categories. Random Forest can handle multiclass classification directly can capture non-linear relationships between audio features and music genres.

After data cleaning and feature selection, the prepared training dataset was used to train the initial Random Forest classification model. The response variable was track_genre, and the predictors included 15 selected Spotify audio and track-level features.

The model was trained using the ranger package in R, which is suitable for building Random Forest models efficiently on large datasets. In this phase, the training dataset contained 91,200 observations. The model was fitted using 300 trees, with mtry = 3 and min.node.size = 5.

The Random Forest model achieved an accuracy of 0.3335 on the testing dataset. This means that approximately 33.35% of the test observations were correctly classified into their actual music genre.

The macro F1-score was 0.3255. Since macro F1-score calculates the F1-score for each class and then averages them equally, it is useful for this multiclass classification task. It gives each genre the same importance, regardless of how many observations each genre contains.

Overall, the model shows moderate performance for an initial multiclass classification model. The accuracy and macro F1-score are both around 0.33, suggesting that the model has learned some useful patterns from the Spotify audio features. However, the performance is still limited, which is expected because the dataset contains many genre categories and some genres may share similar audio characteristics. Therefore, further analysis using the confusion matrix is needed to understand which genres are correctly classified and which genres are commonly confused.

Some blank areas appear in the heatmap because certain actual-predicted genre combinations did not occur in the test results. As a result, audio features alone may not be sufficient to clearly separate all genre categories.

Overall, the normalised heatmap supports the earlier accuracy and macro F1-score results. The initial Random Forest model provides a useful baseline, but further improvement may be needed through hyperparameter tuning, feature engineering, or grouping similar genres.
